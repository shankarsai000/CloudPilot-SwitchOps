# CloudPilot AI — Command Center OS (v2)

## Module ID
**M11-DEMO-V2**

## Layer
Simulation & Orchestration Dashboard

## Overview
The Command Center OS (v2) is a sleek, dark/light theme, Vercel-inspired Single Page Application (SPA). It serves as the primary visualization dashboard for CloudPilot's autonomous cloud intelligence.

## Restructured Core Interfaces:
- **Interactive Topology Graph**: Renders dynamic SVG nodes for providers, VPCs, clusters, and leaf nodes (EC2/RDS instances) with custom inspect behaviors.
- **AI Thinking Timeline**: Animates modules processing statuses sequentially (M1 through M10).
- **Agent Workspaces**: Tabbed workspaces for individual agent modules exposing Inputs, Processing Logs, Outputs, Reasoning, and Decision Council votes.
- **Explainability Center**: Focuses on showing concrete evidence checklists instead of basic summaries.
- **Future Spend Forecast**: Displays projected cost hikes (+6%, +18%, +41%) if no optimizations are run.
- **AI Copilot**: An embedded chatbot answering queries dynamically using current scenario metadata.
- **Guided Story Mode**: Tour orchestrator driving discovery, risk prediction, twin simulations, council reviews, and rollout playback.
